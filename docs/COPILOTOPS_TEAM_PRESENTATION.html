Page 05 - Skill Matrix

Each skill has one backend responsibility.

The power is not calling every skill. The power is selecting the right skills for the task and keeping each skill focused.

sky-api

Controllers, endpoints, routes, DTOs, response contracts.

sky-service

Business rules, handlers, validators, mappings, side effects.

sky-data

EF Core, SQL, entities, migrations, queries, tables.

sky-security

Auth, authorization, tenant isolation, secrets, sensitive data.

sky-performance

Query shape, hot paths, payload size, async flow.

sky-verification

Manual checks, API checks, SQL checks, logs, acceptance criteria.

sky-risk

What can break, rollback, production impact, mitigation.

sky-evidence

Links claims to code, SQL, logs, config, or git evidence.

sky-decision

Compares options when there are multiple realistic paths.

sky-change-summary

Summarizes current git changes for PR or handoff.

Page summary: skills are reusable expert checklists. They make Copilot check backend risk consistently without depending on every developer to remember every concern.
